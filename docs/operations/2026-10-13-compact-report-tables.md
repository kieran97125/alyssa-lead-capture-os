# Fit brand tables before pagination

The editable report keeps one treatment table per brand whenever its complete
rows fit. Remove fixed seven-treatment limits and the forced empty KOL continuation.
For dense tables, widen the name column, use the available space under the title,
reduce body size in half-point steps to a readable 11-point floor and tighten row
padding. Keep native editable cells, complete source labels, original font family,
colors, borders and all metrics. Combine Account/Brand audit rows into one table.

Only sets exceeding the measured canvas at the minimum font size paginate. Such
pages retain exact label reconstruction, count each record once and reconcile page
subtotals. Daily date pages retain their existing layout.

Validation covers eleven mixed-length treatments including three 160-character
names on one slide, long multi-page sets, Account/Brand labels, zero/missing facts,
permission scope, integer OOXML geometry and correct native table/footer bounds.
The actual 1–12 October report is rendered and checked before delivery.

Rollback: revert the renderer and corresponding presentation contracts. The
approved source template and all report/synchronization data remain unchanged.
